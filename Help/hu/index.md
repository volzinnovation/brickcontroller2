# BrickController súgó

A BrickController kompatibilis Bluetooth vevőket vezérel gamepaddel, Powered-Up távirányítóval, támogatott eszközszenzorokkal vagy a HTTP vezérlőfelülettel.

![Alkotások képernyő](../assets/creations-screen.svg)

## Alkotás indítása

1. Nyisd meg a `Creations` nézetet.
2. Nyomd meg a `+` gombot új alkotás hozzáadásához.
3. Add hozzá a modellben használt Bluetooth vevőket.
4. Adj hozzá vagy importálj egy vezérlőprofilt.
5. Rendeld a vezérlő gombjait és tengelyeit a vevőcsatornákhoz.
6. Nyisd meg az alkotást, majd indítsd el a lejátszást.

## Vevő hozzáadása

1. Nyisd meg a `Devices` nézetet.
2. Keress közeli Bluetooth eszközöket.
3. Válassz ki egy támogatott vevőt.
4. Teszteld az egyes csatornákat, mielőtt alkotáshoz rendeled őket.

![Eszközbeállítás képernyő](../assets/device-setup-screen.svg)

## Megosztás és importálás

Az eszköztár műveleteivel fájlként exportálhatod az alkotásokat vagy vezérlőprofilokat, szövegként másolhatod őket, illetve fájlból vagy QR-kódból importálhatod őket.
