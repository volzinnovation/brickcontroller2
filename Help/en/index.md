# BrickController Help

BrickController controls compatible Bluetooth receivers with a gamepad, a powered-up remote, supported device sensors, or the HTTP control interface.

![Creations screen](../assets/creations-screen.svg)

## Start a creation

1. Open `Creations`.
2. Press `+` to add a creation.
3. Add the Bluetooth receivers used by the model.
4. Add or import a controller profile.
5. Map controller buttons and axes to the receiver channels.
6. Open the creation and press play.

## Add a receiver

1. Open `Devices`.
2. Scan for nearby Bluetooth devices.
3. Select a supported receiver.
4. Test each channel before assigning it to a creation.

![Device setup screen](../assets/device-setup-screen.svg)

## Share and import

Use the toolbar actions to export creations or controller profiles as files, copy them as text, or import them from a file or QR code.
