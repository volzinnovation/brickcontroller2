# Help screenshot assets

Place localized screenshots used by the BrickController 2 help pages in this directory.

Recommended files:

- `creation-list.png` — creation selection screen
- `receiver-setup.png` — receiver or hub setup
- `controller-mapping.png` — controller-to-output mapping
- `macos-bluetooth-permission.png` — macOS Bluetooth permission settings
- `http-control-settings.png` — optional HTTP control settings

Capture screenshots from a release build without personal data, device identifiers, access tokens, or private network addresses. Provide localized variants when visible UI text differs, for example `controller-mapping-de.png`.
