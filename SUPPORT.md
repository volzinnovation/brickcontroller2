# BrickController 2 Support

If you need help with BrickController 2, please use one of these resources:

- Read the [English user guide](Help/en/README.md) or [German user guide](Help/de/README.md).
- Search the [existing support requests](https://github.com/volzinnovation/brickcontroller2/issues).
- [Open a new support request](https://github.com/volzinnovation/brickcontroller2/issues/new) for a question, bug report, or feature request.

When reporting a problem, please include your BrickController 2 version, macOS version, controller and hub models, what you expected to happen, and the steps that reproduce the problem. Screenshots or diagnostic details are helpful, but do not post passwords, tokens, or other private information.

BrickController 2 is an independent project and is not affiliated with or endorsed by the LEGO Group.
